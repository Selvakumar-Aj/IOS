# Swift Programming Practice Tasks

Solutions are organized into three units from the supplied practice document.

## Folder structure
- `Unit1_ControlFlow/` — decisions, loops, operators and number exercises (Tasks 1.1–1.18)
- `Unit2_Collections/` — arrays, sets, dictionaries and collection operations (Tasks 2.1–2.18)
- `Unit3_EnumStructClass/` — enums, structures, classes, inheritance and mini project (Tasks 3.1–3.17)

## Run a task
Each `.swift` file is a standalone example. With Swift installed, run one file using:

```bash
swift Unit1_ControlFlow/Task1_1.swift
```

You can also open the file in Xcode or a Swift Playground. Some tasks use sample values; change them to practise with your own inputs.

## Notes
- Each file includes a short comment describing the exercise.
- Tasks are kept separate so each can be run independently.
- Additional guided activities in the source document can be added as separate files if required.
